# Blair's 8-Bit Career Quest — Cloud Architect Chronicles

**An original 8-bit side-scrolling career platformer featuring Blair Page's technical career.**

A fully static, no-build browser game for GitHub Pages. Six side-scrolling worlds, double jumps, sword combat, enemies, collectible crystals, moving platforms, spike hazards, boss fights, checkpoint respawns, educational technical trials, local progress saving, world select, skills, credentials and a recruiter-first résumé view. No paid services, dependencies, accounts, or external runtime assets.

## Publish free on GitHub Pages

1. Create a public GitHub repository named `Blairs-8Bit-Career-Quest`.
2. Upload **all contents** of this repository to the root of its `main` branch (`index.html` must be at root).
3. Go to **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Select `main` and `/(root)`, save, and wait for deployment.
5. Visit `https://blairyfairy.github.io/Blairs-8Bit-Career-Quest/` (once published).

You can also open `index.html` locally. The same static files can be hosted as an HTML5 game on itch.io.

## Controls

| Action | Keyboard | Touch |
|---|---|---|
| Move | A / D or left / right arrows | Left/right buttons |
| Jump, double jump | W, up arrow or Space | Up button (tap twice) |
| Attack | J or X | Sword button |
| Interact | E | E button |
| Pause | P | Pause button |
| World map | M | World Map button |
| Close dialog | Esc | X button |

**Game loop:** Cross each level, collect crystals, jump across ledges, avoid spikes, defeat enemies and the gate boss, then reach the exit portal. Visit the checkpoint terminal halfway through to attempt a simulated technical scenario. Complete all six worlds. Bosses require multiple hits. Progress is saved in localStorage; the World Map includes a reset option.

## Worlds

1. Linux Citadel — L3 hosting, Linux, web servers
2. Cloud Spire — AWS, OpenStack, IaaS
3. Data Vault — MySQL, Percona, MongoDB, Redis
4. Commerce Port — Magento, WordPress, WooCommerce
5. Automation Forge — Ansible, containers, observability
6. Origin Guild — classic private MMORPG game-server administration
